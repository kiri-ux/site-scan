Rationale

  • Above bare CMPs, below Lokker — exactly what the feature set is.
  • $99–149 matches Code-Cube's entry tier (1 domain, 1 scan/day, no consent testing, no products).
  • Consider free monitoring above a spend threshold — protects Vici's campaign data anyway.
  • 100 sites × $40 ≈ $4K/mo vs ~$50 infra — legal paperwork before the first invoice.
  • Lokker / ObservePoint aren't price competitors — they're the attestation layer to add later.

Open decisions

  1. Price point — pick within the ranges.
  2. Bundle vs. add-on — free above spend threshold, always billed, or free for all clients?
  3. Legal gate — counsel-reviewed ToS + E&O before client-facing; check-based language throughout. State-law check map for legal review →
  4. Vendor layer — Lokker as attestation for paying accounts, or self-serve only?
  5. Next build — GTM API config audit (Cloud project + Tag Manager API + OAuth).

Legal posture — how we protect ourselves

▶
  • Check-based language, never legal conclusions — reports say "fails the GPC check — required for CA targeting," never "violates California law." Compliance depends on facts we can't see; asserting it creates the liability.
  • No "compliant," "certified," or "passed" anywhere in product copy or reports — "no issues detected in checked items" is the ceiling.
  • Scope disclaimer travels with every report — point-in-time, scanned pages only, load-time behavior only. Already baked into share-page footers.
  • Counsel-reviewed ToS before client-facing — informational tool, no guarantee of compliance, liability capped at fees paid, consequential damages excluded, client owns their own legal compliance.
  • E&O confirmation — one broker call to confirm tech E&O covers a software service with automated outputs, before the first invoice.
  • Alert-handling SOP — selling monitoring creates a duty to act on findings; document who tells the client, how fast, and where it's logged. "Flagged in March, mentioned in June" is worse than never scanning.
  • Quarterly state-map review — the check map is static, cited, and counsel-reviewable; the scanner nags when the review date lapses.
